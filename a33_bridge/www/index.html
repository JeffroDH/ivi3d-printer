Z Offset (mm)

Z offset: +0.00 mm

Offset is 0.00 after calibration or after you set zero. + means the nozzle is higher than that reference, − means closer. Save writes a new stored height (M665 H + M500) but keeps this displayed offset. Mid-print, save is queued until idle. A stock paper-test calibration resets the reference to the new height so the offset reads 0.00 again.

Off by default. When on, a successful Upload and Print skips the plate-warning dialog and starts the job the same way the touchscreen RUN button does. When off, you still confirm OK and RUN on the screen.

Calibration

XYZ (G33) takes about 15 minutes and clears the bed mesh, so it always continues into auto-level (G29). Keep the probe on between those two. The paper test is done with the probe off. Settings are saved (M500) only after a successful “Calibration OK” or a complete leveling grid, or when you save the paper test. Cancel stops without saving.

G33 solves endstops (M666), height H, radius R, and tower angles. It does not change the probe offset (M851) and it wipes the 7×7 mesh, so leveling always follows.

7×7 bilinear mesh.

Not run from this page yet.

The firmware grid is fixed at 7×7 (about 35 mm spacing over a 210 mm square). A finer 12×12 grid would need a firmware change.
